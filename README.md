# APP — Advanced Programming Practice

An immersive visual learning platform for Advanced Programming Practice.

## Vision

Learn programming concepts by seeing, interacting, experimenting, and then coding — not by reading static notes alone.

## Learning model

**Understand → Visualize → Interact → Code → Experiment → Recall**

The platform is designed around reusable concept experiences: interactive flowcharts, dynamic diagrams, execution visualizations, code walkthroughs, comparisons, simulations, and micro-challenges.

## Planned stack

- Next.js + React + TypeScript
- Tailwind CSS
- Motion
- React Flow + SVG + D3 where appropriate
- MDX-driven course content
- Monaco Editor for interactive code
- Supabase for persistence and progress
- Vercel for deployment

## Initial flagship experiences

1. Programming Paradigm Hierarchy
2. Structured Programming
3. Object-Oriented Programming
4. Subroutines vs Methods
5. Object Serialization
6. Parallel Computing

The goal is to establish a high-quality reusable learning engine first, then scale it across the APP syllabus.
